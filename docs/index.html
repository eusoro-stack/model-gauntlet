What the tasks measure

constraints — exact bullet counts, exact word counts, forbidden words. Trivial to state, brutal to obey.
json_discipline — strict schema output, no fences, no prose. Fitness test for bot and tool-call duty.
orchestrator — the model writes a plan() function and it is graded by executing it against hidden tests, including a cycle-detection case and an alphabetical tiebreak.

A note on the scoring

An earlier version of these graders stopped early when a response was too malformed to keep testing — unparseable JSON, code that wouldn't execute. That shrank the denominator and quietly rewarded the worst failures: 0/2 costs less than 0/5. Three models were flattered by it before an audit caught it. Every result now pads to the full check count, so a broken response is always measured against the full bar.
